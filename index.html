How I build

Two kinds of systems.

Web apps and data pipelines take different muscles. I build both, with AI agents doing much of the typing and me doing the architecture.

Web apps

NYX: multi-agent orchestration with streaming, per-step token and latency logs. FORGE: an installable app with row-level security on every table. TONED: mobile app, admin panel and payment webhooks.

Data pipelines

RME: certificate PDF → structured JSON → validation → Oracle Unifier template, plus a BOQ revision diff and pgvector search with citations. FORGE: photo → background job → schema-checked extraction → athlete confirms.

Agentic workflow

Claude Code and OpenAI Codex, driven by written specs in each repo (CLAUDE.md, AGENTS.md), MCP servers, and tests and evals that check the agents’ output.
